# Plan de campo en una página

Junta lo que armaron la guía, la muestra y el plan de observación. Se lee antes de la primera sesión y se acuerda con quien patrocina la investigación. La mayoría de las investigaciones que salen mal no fallan por el método: fallan porque alguien esperaba otra cosa.

```markdown
# Plan de campo | [Proyecto]

**Decisiones que alimenta:** [arriba de todo, para que nadie se olvide para qué es]

## Preguntas de investigación
1. [la más importante]
2.
3.
(De 3 a 5. Si salen más, se recorta ahora, no en el análisis.)

## Métodos
| Método | Por qué este | Qué no va a poder responder |
|---|---|---|
| Entrevistas | | |
| Observación | | |

## Muestra
| Lado o segmento | Cuántos | Cómo se recluta | Quién recluta |
|---|---|---|---|

## Calendario
| Semana | Qué pasa |
|---|---|
| 1 | Reclutamiento (suele tardar más de lo que se cree) |
| 2 a 3 | Sesiones, con el debrief de cada una dentro de las 24 horas |
| 4 | Síntesis |
| 5 | Presentación de resultados |

## Quién hace qué
| Rol | Persona o equipo |
|---|---|
| Conduce las entrevistas | |
| Toma notas | |
| Recluta | |
| Observa en campo | |
| Sintetiza | |
| Recibe los resultados, y cuándo | |
```

Si el calendario no entra en el tiempo disponible, se recorta alcance y se dice. No se aprieta el campo: un plan que supone que la parte de hablar con personas se puede saltear no es un plan de investigación.
