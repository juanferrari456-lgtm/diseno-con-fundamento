# Hoja de registro

Una para todos los observadores, para que las notas se puedan juntar. Las columnas siguen los pasos del servicio, así cada nota entra directo al blueprint (`pensar-blueprints`) y al tablero de campo (`sintesis-de-campo`).

```markdown
# Registro de observación | [Proyecto]

| | |
|---|---|
| Observador | [rol o código] |
| Lugar | |
| Fecha | |
| Desde y hasta | |
| Condiciones | [día normal, pico, clima, algo fuera de lo común] |

| Hora | Momento o paso | Front o back | Qué pasó | Qué se usó | Qué se dijo | Sorpresa | Hipótesis |
|---|---|---|---|---|---|---|---|
| 19:05 | Acceso | Front | Fila de 12 personas, una sola persona validando | Lector y planilla en papel | "Siempre es así a esta hora" | La planilla de papel reemplaza al lector cuando falla | H3 |
```

## Cómo llenarla

- **Hora en cada nota.** Permite cruzar con el dato operativo del mismo momento.
- **Qué pasó, sin interpretar.** "Le pidió el documento dos veces", no "estaba desconfiado". La interpretación va en el debrief.
- **Qué se dijo, textual y corto.** Sin nombres: rol o código.
- **Qué se usó:** sistemas, papeles, herramientas, atajos. Es donde aparecen los sistemas que nadie mapeó.
- **Sorpresa:** lo que no esperabas. Es la columna más valiosa.
- **Hipótesis:** si la nota toca una, su ID. Si no toca ninguna y pesa, va igual: puede ser una hipótesis nueva.
